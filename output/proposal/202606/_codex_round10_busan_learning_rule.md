# 10차 — 부산 신규 지점 학습 예산 룰 수치 확정

R9에서 부산 처리는 "1.65M 일관 산식" 대신 **"최소 집행액 + 2주 관찰 + CPA/CVR 기준 통과 시 증액"의 학습 예산 룰**로 결정됐습니다. 그러나 구체 수치가 미정이라 운영팀이 즉시 적용 불가합니다. R10에서 5개 파라미터를 확정합니다.

## 컨텍스트 (변경 불가)

- 부산은 2026-05-15경 신규 개설 → 5월 부분월 데이터 약 15일치
- 5월 부분월 비용 약 687,635원 (일평균 약 45,800원)
- 다이트한의원 9개 지점 정상월(2~4월) CPA 중앙값 약 27,278원
- 다이트한의원 9개 지점 정상월 CVR 평균 약 6.07%
- 6월은 30일 정상 운영 첫 달 (학습 종료 → 정식 운영 진입 시점)
- 다른 지점은 정상월 평균 ±10% 산식으로 권장 예산 산출 (월 2~3.87M 분포)

## R10 결정 요청 1. 6월 최소 집행액

부산 6월 학습 예산의 floor(최소 집행액):

옵션:
- (a) 687K — 5월 부분월 비용 그대로 유지 (실집행 검증된 수준)
- (b) 1,000,000원 — 라운드 숫자, 일평균 약 33K → 30일 학습 충분 노출 보장
- (c) 1,200,000원 — 다른 지점 권장 평균(2.1M)의 약 57%로 "학습 단계"임을 명시
- (d) 일평균 45,800원 × 30일 = 약 1,374,000원 (단순 환산)

**Q1**: 최소 집행액 a/b/c/d 중? 또는 다른 수치?

## R10 결정 요청 2. 관찰 기간

R9에서 "2주"가 제안됐으나 다이트 운영 사이클에 맞는지:

옵션:
- (a) 2주 (6/1~6/14) — codex R9 제안. TikTok 학습 알고리즘 안정화 기간과 정합
- (b) 3주 (6/1~6/21) — 위클리 리포트 2회 사이클 (월요 발행 기준 6/8, 6/15)로 의사결정 데이터 2회 누적
- (c) 4주 (6/1~6/30) — 한 달 전체 학습 후 7월 정상 진입. 6월에는 증액 결정 안 함
- (d) 데이터 트리거 (cumulative clicks ≥ 200 OR conversions ≥ 20 도달 시점) — 시간이 아닌 볼륨 기준

**Q2**: 관찰 기간 a/b/c/d 중? 다이트 위클리 사이클(매주 월요일 발행)과의 정합성 고려.

## R10 결정 요청 3. CPA 통과 기준

학습 기간 종료 시 "정상 운영 진입 = 증액 가능" 판정의 CPA 임계:

옵션:
- (a) 부산 누적 CPA ≤ 9개 지점 평균 CPA (약 27,278원) — 평균만 통과해도 OK
- (b) 부산 누적 CPA ≤ 9개 지점 평균 CPA × 1.2 (약 32,734원) — 학습 단계 관대 허용
- (c) 부산 누적 CPA ≤ 9개 지점 평균 CPA × 0.8 (약 21,822원) — 평균보다 우수해야 증액
- (d) CPA만으로 판단 불가 — CPA + CVR 동시 통과 필요 (Q4 별도 결정)

**Q3**: CPA 기준 a/b/c/d 중? 신규 지점 학습 단계의 관대함과 효율 기준 사이 트레이드오프.

## R10 결정 요청 4. CVR 통과 기준 (CPA와 AND 조건)

CPA와 함께 평가할 CVR 임계:

옵션:
- (a) 부산 누적 CVR ≥ 9개 지점 평균 CVR (약 6.07%) — 평균 도달 필요
- (b) 부산 누적 CVR ≥ 9개 지점 평균 CVR × 0.8 (약 4.86%) — 학습 단계 관대
- (c) 부산 누적 CVR ≥ 5.0% — TIER1 기준값(절대) 사용
- (d) CVR 기준 생략 — CPA만으로 충분

**Q4**: CVR 기준 a/b/c/d 중? CPA와 CVR 동시 통과(AND) vs OR 조건은?

## R10 결정 요청 5. 통과/미통과 시 처리

학습 종료 시 의사결정 트리:

옵션:
- (a) 통과 → 정상 산식 적용(평균 ±10%) → 약 1.9~2.0M 권장 / 미통과 → 학습 예산 유지 + 추가 관찰
- (b) 통과 → 단계적 증액(통과 즉시 +30%, 1주 후 +30% 추가, 총 약 1.1~1.2M) / 미통과 → OFF + 소재 전면 재검토
- (c) 통과 → 다른 지점 평균까지 1회 증액 (약 2.1M) / 미통과 → 학습 예산 50% 감액 후 재시작
- (d) 통과/미통과 무관 6월 내 증액 없음, 모든 의사결정 7월로 이관

**Q5**: 처리 트리 a/b/c/d 중? 신규 지점의 sunk cost 회피와 성장 기회 사이 균형.
