# 11차 — 애드온 분석 보완 범위 결정

## 배경

R10 이후 사용자가 "애드온 분석이 어느 시점부터 포괄적으로 안 된 것 같다"고 우려를 제기했습니다. 실제 데이터를 검증한 결과 단일 합산 비교만으로는 잘못된 결론을 낼 수 있는 양상이 드러났습니다. 보완 범위를 결정합니다.

## 데이터 검증 결과 (실 측정값)

### 1. 전체 합산 (현재 5.2 섹션에 표시 중)
- 애드온 CVR **6.67%** vs 비애드온 **5.79%** (+0.88pp)
- Z-test p = **0.0009** → 통계적으로 유의
- CPA 25,611원 vs 28,999원 → **-11.7%**
- → 표면적으로는 "애드온 좋음" 결론

### 2. 동일 매칭키 페어 비교 (selection bias 제거)
- 10개 페어 가능 매칭키 (양쪽 모두 클릭 ≥100)
- 8/10에서 애드온 CVR 높지만, **통계적으로 유의한 건 3개뿐**
- 7개는 우연 가능성

### 3. 소재유형별 분해

| 소재유형 | CVR Δ | CPA Δ% | p-value |
|---|---|---|---|
| 인플방문후기 (클릭 11K) | +1.18pp | +6.0% | **0.0179 ★** |
| 진료셀프캠 (클릭 22K) | +0.5pp | -20.0% | 0.15 |
| 의료진정보 (클릭 4K) | -0.07pp | **+44.4%** | 0.95 |

→ 인플방문후기에서만 통계적으로 유의. 의료진정보는 표본 작지만 CPA 44% 악화 신호.

### 4. 월별 추세 (가장 중요)

| 월 | 애드온 CVR | 비애드온 CVR | Δ | p-value |
|---|---|---|---|---|
| 3월 | 7.18% | 5.49% | **+1.69** | **0.0301 ★** |
| 5월 (부분) | 6.03% | **9.76%** | **-3.73** | **0.006 ★** |

→ 3월에는 애드온 유리, 5월에는 비애드온 유리로 **역전**. 5월 비애드온 표본이 작긴 하지만(338 클릭) 통계적으로 유의.

### 데이터의 한계

- 5월은 부분 데이터(2/3~5/15)
- `addon_kind`는 단일 'display_card'만 존재 (메타에 다양성 없음)
- 부산·대전은 표본 너무 작음 (애드온 광고 2~9개)

## 현재 제안서의 한계

현재 5.1~5.5는 "**전체 -11.7% CPA 개선**" 단일 메시지만 전달. 위 4개 발견 중:
- 통계적 유의성 검증 없음
- 소재유형별 차이 안 보임 (의료진정보의 역효과 놓침)
- 월별 추세 없음 (5월 역전 안 보임)
- 5.5 실행 가이드는 "W1 A/B → W2 평가 → W3-4 확대" 일반 절차만

## 제안된 4개 보완안

- **(A)** `analyze_addon_effect.py`에 소재유형별 분해 + p-value 추가
- **(B)** 월별 추세 분해 추가 (시점별 효과 변화 감지)
- **(C)** 5.5 실행 가이드를 데이터 기반 처방으로 재작성 — 인플방문후기 확대 / 의료진정보 보류 / 5월 역전 원인 조사
- **(D)** 표본 부족 경고 (클릭 <100 등) caution badge

## codex 결정 요청

### Q1. 4개를 모두 진행하는 게 맞는가?

옵션:
- (a) **A+B+C+D 모두** — 가장 포괄적이지만 구현 부하 큼. 5.x 섹션이 길어질 위험
- (b) **A+B+C만** — 통계 유의성·월별 추세·재작성. (D) 표본 경고는 inline 메모로 충분
- (c) **A+C만** — 가장 핵심 (소재유형 분해 + 데이터 기반 처방). (B) 월별 추세는 부록으로
- (d) **C만** — 5.5 실행 가이드만 데이터 기반으로 재작성. 나머지는 현재대로 (단일 합산)

추천 (검증 요청): **(a)** 가 진실에 가장 가깝지만 (b) 또는 (c)가 컨설팅 제안서의 적정 깊이일 수 있음. **5월 역전이 6월 운영 결정에 직접 영향을 주는 신호**라서 (B) 월별 추세는 빠질 수 없다고 봄.

**Q1**: (a)/(b)/(c)/(d) 중 어느 안? 다른 조합이 더 적절한 경우는?

### Q2. 월별 역전(3월 +1.69 → 5월 -3.73)을 어떻게 본문에 표현할까?

5월 비애드온 표본 338 클릭은 작아서 "완전한 결론"으로 표현하면 위험. 그러나 통계적으로 유의(p=0.006). 옵션:

- (a) 본문에 강하게 표시 — "5월 역전 발생, 6월 운영 전 원인 조사 필수"로 결재 요청
- (b) caution badge와 함께 중간 강도로 — "5월 표본 적음(부분월) 단, 통계적으로 유의한 변화 신호"
- (c) 부록에만 기록, 본문은 "전 기간 추세" 평탄화
- (d) 본문에 표시하되 결론은 "원인 가설 3개 (신규 소재 도입 / 알고리즘 변화 / 광고 그룹 ON/OFF 패턴 변화)" 제시 후 클라이언트가 확인 후 결정

추천: **(d)**. 데이터는 정확히 전달하되 단정짓지 않음. 가설을 명시하면 클라이언트가 운영 사이드에서 검증 가능.

**Q2**: 동의? 다른 표현 방식?

### Q3. 의료진정보 소재유형의 CPA +44.4% 악화는 본문에 어떻게?

표본이 작음 (애드온 클릭 439, 전환 21건). p=0.95로 통계적 유의성 없음. 그러나 데이터 표면값은 명확히 부정적.

- (a) 본문 미언급 — 표본 부족이므로 위험. 부록에만
- (b) "예비 신호" 수준으로 표시 — "표본 부족이나 CPA 악화 방향 관찰. 추가 운영 데이터 확보 후 결론"
- (c) 본문에 표시 + 6월 운영에서 의료진정보 + 애드온은 보류 권고

추천: **(b)**. 통계적으로 안 가도 비즈니스적으로 무시할 수 없는 신호. 단, 단정 금지.

**Q3**: 동의?

### Q4. 단일 'display_card' addon_kind를 활용해야 하는가?

- (a) 코드에서 제거 (불필요)
- (b) 유지 (다중 종류 도입 시 자동 작동)

추천: **(c)**. 향후 확장성 표시.

**Q4**: 동의?

### Q5. 5.x 섹션을 어떻게 재구성할지

현재 5.1~5.5 (5개 서브섹션). 4개 보완 모두 추가하면 6~8개 서브섹션 가능. 옵션:

- (a) 기존 5.1~5.5 구조 유지 + 5.4·5.5 내부 콘텐츠만 데이터 기반으로 재작성
- (b) 5.1 판단 / 5.2 합산 / 5.3 소재유형별 (신규) / 5.4 월별 추세 (신규) / 5.5 페어 / 5.6 실행 가이드 (재작성) — 6개로 확장
- (c) 5.1 판단 / 5.2 합산+소재유형 (통합) / 5.3 페어 / 5.4 시점·실행 (월별 추세 + 실행 가이드 통합) — 4개로 압축
- (d) 본문은 5.1~5.3만 (판단·합산·소재유형) + 부록 5.A에 페어·월별·통계 디테일

추천: **(c)** 또는 **(d)**. 컨설팅 제안서는 본문 압축이 가독성에 유리.
