# 4차 — 비용·예산 분석 추가 논의

지난 3라운드(R1~R3)에서 보고서 큰 골격은 확정했고, 사용자가 이번에 새로 짚어준 부분이 비용·예산 분석 부족입니다.

## 사용자 요청 (정확히)
> 월 집행 예산에 따라서도 분석이 충분히 진행되었는지 확인 부탁해.
> 월 목표 예산은 차치하고, **실 집행 예산 대비 성과 분석**이 필요해. 그래서 **6월 목표값을 위한 목표 예산이 산정**되면 될 것 같아.

## 현 상황
- 보고서가 지금까지 비용(cost) 데이터를 거의 노출하지 않음 (사분면 차트 버블 크기 정도)
- 지점별 누적 비용·월별 비용 추이·예산 권장 모두 없음
- 새 모듈 `analyze_budget.py`를 만들었는데, 처음엔 MONTHLY_BUDGET(CLAUDE.md에 정의된 계획 예산)을 베이스로 잡았으나 사용자가 **그건 차치하라**고 지시
- 핵심은:
  1. 실집행 예산 대비 성과 (어디에 얼마 쓰니 무엇이 나왔는가)
  2. 6월 목표값(전환 762건 base / Stretch 822건, CPA 27,278원, 지점별 CPM/CTR/CVR 목표 별도)을 달성하기 위한 **6월 필요 예산 역산**

## 이미 확정된 6월 목표값 (지점별 베스트월 재달성 기준)
- 전 지점 합산 base = 762건 (4월), CPA 27,278원 (2월)
- 전 지점 합산 stretch = 822건 (지점별 베스트월 합산)
- 지점별 전환 베스트, CPA 베스트 모두 산정 완료 (`june_targets.by_branch`)

## 현 데이터에서 끌어올 수 있는 비용 지표
- 월별·지점별 cost / conversions / cpa (정상월 2~4월 + 부분월 5월)
- 정상월 평균 월간 집행 = 2~4월 합계 ÷ 3
- 지점별 전 기간 누적 비용
- 전 지점 평균 CPA = 27,814원 (전 기간 누적)

## codex에 검토 요청 사항

### 1. 6월 목표 예산 역산 로직 — 어떤 방식이 적절한가?

옵션 A) **단순 곱셈**
```
6월 필요 예산 = Σ(지점별 전환 베스트월 목표) × 지점별 CPA 베스트월 목표
```
- 가장 낙관적. 모든 지점이 본인 베스트 CPA·전환을 동시 달성한다고 가정
- 단점: 베스트 CPA는 비용 적게 쓰고 CPA 낮춘 월이므로, 그 효율로 전환수 베스트(비용 많이 쓴 월)를 만든다는 가정이 양립 어려움

옵션 B) **시나리오 3종 (낙관/현실/보수)**
```
낙관: Σ(전환 stretch × CPA 베스트월)
현실: Σ(전환 base × CPA 평균)
보수: Σ(전환 base × CPA 최악월)
```
- 범위로 제시. 클라이언트가 전략 선택 가능

옵션 C) **전환 목표 기준 단일 예산** (현실 기준 1개)
```
6월 필요 예산 = Σ(전환 base 목표 × CPA 정상월 평균)
```
- 단일 값. 의사결정 단순. Stretch 도달 시 추가 예산 가이드만 명시

옵션 D) **지점별 효율 등급 기반 가중**
```
지점별 예산 = 현재 평균 월간 집행 × (효율 양호 +10% / 평균 ±0% / 부진 -10% / 신규 유지) 
6월 합계 = 위 합산 + 전환 갭 보정
```
- 실집행 베이스라인 + 효율 가중. 사용자 의도("실집행 대비 성과")에 가장 부합

→ **사용자 의도 정확히 반영하면 어떤 옵션 또는 조합이 좋은지** 의견 부탁

### 2. "실집행 예산 대비 성과 분석"의 적절한 측정 지표

후보:
- a) **비용 비중 vs 전환 비중 매칭** (지점별 비용 비중 X% vs 전환 비중 Y% → Y/X 비율이 효율 점수)
- b) **CPA만 비교** (이미 보고서 곳곳에 있음)
- c) **100만원당 전환수** (전 지점·지점별·월별 비교 가능, 직관적)
- d) **누적 비용 vs 누적 전환 산점도** (사분면 차트의 단순 버전)

어떤 조합이 컨설팅 보고서에서 한눈에 들어올지

### 3. 5월 부분 데이터 처리

5월은 운영 중단으로 비용이 정상월의 약 1/3 수준 (7.4M vs 평균 18.6M). 5월을 어떻게 다룰지:
- 평균 월간 집행 계산에서 5월 제외 (정상월 2~4월만)
- 월별 추이 차트에는 5월을 부분 색상으로 표시
- 5월 자체의 CPA(20,747원)가 평균보다 양호한데, 운영 중단 직전이라 노이즈로 해석할지 신호로 해석할지

### 4. 보고서 통합 위치 — 3곳 적절한가?

A. P0 Executive Summary의 Primary KPI 3번째 카드 (현 "비용 규모")
   → **"월 평균 집행 · 6월 필요 예산"** 으로 변경

B. P1 진단 탭의 신규 섹션 "2.4 비용·예산 효율"
   - 월별 총비용 추이 차트 (2~5월, 5월 부분 색)
   - 지점별 비용·전환 매칭 표 (실집행·비중·효율점수)
   - Lead: "비용 비중 대비 전환 비중이 어디서 맞고 안 맞는지"

C. P2 6월 목표·액션 Master Table에 컬럼 추가
   - 실집행 평균 / 6월 권장 예산 / 증감%

→ 추가/삭제/병합할 부분 있는지
