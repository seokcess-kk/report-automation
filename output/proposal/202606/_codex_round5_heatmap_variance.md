# 5차 — 월별×지점별 퍼널 히트맵 변동 원인 진단 로직 검토

지난 4라운드(R1~R4)에서 보고서 골격·예산 분석까지 확정한 상태입니다. 이번 라운드는 클라이언트(다이트한의원)가 추가로 요청한 **2.3 히트맵의 월별 변동 원인 분석**을 어떻게 데이터 기반으로 정확하게 구현할지에 대한 검토 요청입니다.

## 사용자 요청 (정확히)
> 월별 × 지점별 퍼널 히트맵에서 지점별 월별 차이가 발생한 원인 분석이 가능할까?
>
> CPM은 2월 성과가 제일 좋은 반면 지날 수록 높아지고, CTR은 낮았다가 갈 수록 높아지고, CVR은 조금 뒤죽박죽이긴 하니까 이에 대한 분석이 들어가면 좋을 것 같거든. 예를 들면 서울점의 CPM이 높아진 이유는 ~~~~ 때문이다. 이런 내용 말이야.
>
> **애매한 추측이 아니라 데이터에 기반한 정확한 원인 진단이어야 해. 그 원인에 따라 운영 정책이 바뀔거니까 말이야.**

## 컨텍스트

- 현재 2.3 섹션은 월×지점 히트맵 3개(CPM/CTR/CVR)만 보여줄 뿐 변동 원인은 침묵
- 클라이언트는 "원인 → 운영 정책" 연결을 명시적으로 요구 (이번 라운드의 핵심 제약: 원인이 정확해야 정책이 바뀜)
- 현재 보고서 곳곳의 진단(`analyze_root_cause`, `consulting_signals`)은 전체 누적 기준이라 **월별 변동을 설명하지 못함**

## 데이터 가용성 (parsed.parquet 기준)

각 행 = (date, ad_name, branch, creative_type, creative_name, cost, impressions, clicks, conversions, landing_views, is_off, attribution_caution).

분해 가능한 차원:
- **소재유형(creative_type)** — 의료진형 / 방문후기 / 다이어트(여성) 등 7종
- **광고 단위(ad_name)** — 신규/기존 구분 가능 (해당 월 이전 운영 여부)
- **매칭키(creative_name)** — 소재 식별자 (광고 단위의 부모)
- **활성/OFF(is_off)** — 현재 상태
- **일별 cost / 일별 impressions / 일별 clicks / 일별 conversions / 일별 landing_views**

분해 불가 (데이터 외부):
- 입찰 단가, 일일 예산 캡 (지점별 광고 그룹 단위 — meta에 없음)
- 타겟팅 변경 이력 (있는지조차 부정확)
- 랜딩 변경, 상담 응대, 외부 시즌성

## 핵심 아이디어 — Oaxaca-Blinder 분해

월별 평균 CPM 변화를 다음 두 요인으로 **결정론적으로(=산술적으로)** 분해할 수 있습니다.

```
ΔCPM(t→t+1) = Σ_j [ Δshare_j × CPM_j(t) ]    ← mix effect (소재유형 비중 변화)
            + Σ_j [ share_j(t+1) × ΔCPM_j ]   ← within effect (같은 유형 내 단가 변화)
            + 잔차 (상호작용항)
```
- `share_j` = 소재유형 j의 노출 비중
- `CPM_j` = 소재유형 j의 평균 CPM

같은 분해를 CTR·CVR에도 적용 가능:
- ΔCTR = mix effect + within effect (단, CTR은 clicks/impressions이므로 weighted by impression share)
- ΔCVR = mix effect + within effect (weighted by click share)

분해 결과의 의미:
- **mix effect 우세** → 운영 정책: 소재유형 비중 조정 (어떤 유형을 줄이고 어떤 유형을 늘릴지)
- **within effect 우세** → 운영 정책: 외부 요인 진단 필요 (입찰 경쟁 강도, 타겟 풀 포화, 랜딩 정합성 등) — 광고 운영 외부 영역
- **mix + within 동시 우세** → 두 정책 병행

이게 "**애매한 추측이 아닌 데이터 기반 정확한 원인 진단**"의 핵심 — 분해 결과는 산술적이므로 반박 불가.

## 보조 시그널 (분해를 보강)

분해만으로 부족할 때 보강할 5가지 결정론적 시그널:

1. **신규 ad_name 비중** — 그 달 첫 등장한 ad_name의 노출/비용 비중. 신규는 학습 기간이라 CPM 일시 상승 경향
2. **OFF 전환 영향** — 그 달에 OFF된 ad_name 중 전월에 우수 성과(평균 CPA 이하)였던 비율
3. **소재 mix 차이** — Jensen-Shannon divergence(또는 단순 max |Δshare_j|)로 mix 변화량 정량화
4. **일평균 cost 변화** — 일평균 예산 자체가 흔들렸는지 (예산↑ → 보통 노출 단가↑)
5. **집행일수 / 활성 ad_name 수** — 캠페인 규모 변화

각 시그널에 임계값을 두고 통과한 시그널만 진단문에 인용.

## 임계값 제안 (검토 필요)

- 변동 셀로 인정: 그 지점의 그 지표가 **해당 지점 전 기간 평균 대비 ±15% 이상** 차이 (지점 내 자기 평균 비교 → 지점 간 절대값 차이 영향 제거)
- 분해 effect 인정: |effect contribution| ≥ Δ전체의 30%
- 보조 시그널 인정 임계: 신규 비중 ≥25%, OFF 영향 ≥15%, 소재 mix max |Δshare| ≥10%p, 일평균 cost Δ ≥20%, 집행일수 Δ ≥30%

## 출력 형식 제안

2.3 히트맵 evidence-card 바로 아래에 신규 sub-section:

```
2.3.1 히트맵 변동 주원인

전체 트렌드 (한 줄)
  CPM 2월 X원 → 5월 Y원 (+34%) · CTR N% → M% (+12%p) · CVR ±Z%

지점·지표별 변동 카드 (±15% 이상 셀만, 우선순위 정렬, 6~9개)
  ┌──────────────────────────────────────────────────────┐
  │ [서울 · CPM ↑34%]   2월 8,900원 → 5월 11,920원       │
  │ ─────────────────────────────────────────────────── │
  │ mix effect  +18%p · 의료진형 비중 +25%p (CPM 평균    │
  │              13,400원, 후기형 9,200원 대비 +46%)     │
  │ within effect +16%p · 동일 소재의 평균 CPM이 자체적  │
  │              으로 +1,800원 상승 (외부 요인)          │
  │ 운영 함의 · 의료진형 비중 30% 이하로 환원하면 CPM     │
  │              약 9,300원 회복 예상                    │
  └──────────────────────────────────────────────────────┘
```

각 카드는:
- 헤더: `[지점 · 지표 변화율]` + 시작·종료 월 수치
- 본문: 분해된 effect 한 줄씩 + 정확한 수치 (`+25%p`, `13,400원` 등)
- 운영 함의 한 줄 (decomposition 결과를 정책으로 환원)

## codex 검토 요청 사항

다음 6가지에 대해 결론 먼저, 근거 뒤로 답변 부탁드립니다.

### 1. Oaxaca-Blinder 분해의 정확성
- mix/within 2요인 분해가 광고 데이터에 적절한 통계 기법인지
- 잔차(상호작용항) 처리: 무시? mix에 합산? within에 합산? 평등 분배?
- CTR·CVR 분해 시 가중치를 impressions/clicks로 잡는 게 맞는지

### 2. 분해 단위 — creative_type vs ad_name
- mix를 **소재유형(7종)** 단위로 잡을지, **광고(ad_name, 수십 개)** 단위로 잡을지
- 광고 단위는 신규/기존 자연 구분, 소재유형은 운영 정책 직결
- 또는 2단계 분해 (먼저 신규/기존 ad_name → 그 다음 소재유형) 가능한지

### 3. 신규 ad_name 정의
- "신규" 정의: (a) 해당 월에 처음 운영된 ad_name (b) 직전 월에 운영되지 않은 ad_name (c) 직전 30일에 운영되지 않은 ad_name
- 분기점이 월 경계라 (a)와 (b)는 다름 (a)는 2월 신규가 5월에도 "신규" 아님
- 클라이언트 의사결정에 가장 유의미한 정의는?

### 4. 임계값 설정 — ±15% / 30% / 25%
- 변동 셀 인정 임계 (지점 자기평균 ±15%) — 5월 부분월 노이즈와 정상월 변동을 구분할 수 있는 적절한 컷오프인가
- effect contribution 임계 30% — 너무 관대하지 않은가
- 보조 시그널 임계값들 — 데이터를 실제로 보지 않은 상태에서 reasonable한지

### 5. CVR 진단의 한계
- CVR은 광고 외부 요인(랜딩, 상담 응대)이 결정적
- 분해 결과 within이 압도적으로 우세하면 "랜딩·응대 점검 요청"으로 환원되어 보고서가 클라이언트에게 책임 전가로 읽힐 위험
- CVR 진단을 별도 톤으로 처리해야 하는지

### 6. 5월 부분월 처리
- 5월은 운영 중단 부분월 (총 비용 정상월의 1/3, 일수도 짧음)
- 분해 시 5월을 정상 비교 대상에 포함할지, 별도 표기만 할지
- 사용자가 강조한 "지날수록" 트렌드에는 5월 포함이 자연스러우나 분해 정확도는 떨어짐
