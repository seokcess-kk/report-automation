# 9차 — 적대적 재검토: R8 합의의 약점·블라인드스팟·놓친 위험

R8에서 6개 결정이 합의됐고 codex가 추가로 2가지 우려를 제기했습니다(부산 보정 시 총액 20.17M, normalize 보조 표 필요). 그러나 R8의 응답이 모두 "동의" 일색이었던 점에서 **프레이밍 편향(anchoring) 의심**이 있습니다. R9는 **devil's advocate 모드**로, 각 합의를 비판적으로 재검토합니다.

## R9 운영 원칙

1. 아래 6개 합의 각각에 대해 **가장 강한 반박 논거**를 제시해주세요. "맞다"는 응답 금지.
2. R8 추천에 매몰되지 말고 **제3의 옵션**이 가능한지 적극 탐색.
3. 마지막에 "R8에서 우리 둘이 모두 놓친 가장 위험한 누락 1~2개" 식별.
4. 비판이 약하거나 "전반적으로 적절"식 응답은 R9 목적 위반. 구체적 약점이 없으면 "약점 없음 — 근거: ..."로 명시.

## R8 합의 1. 19.21M 권장 유지 + 결재 박스 (Q1=b)

합의된 결정의 약점:
- 클라이언트가 "왜 데이터 분석 결과가 이미 정해진 가이드라인을 넘어서?"라고 받으면 분석의 신뢰도 자체가 의심받을 수 있음
- 결재 박스 = 책임 전가로 읽힐 위험

**Q1-반박**: 이 결정의 가장 큰 운영 리스크 1개를 짚어주세요. 또는 (a)/(c)/제4안이 실제로 더 적절한 경우는?

## R8 합의 2. KPI 891 vs 권장 711 갭의 차트 병기 (Q2=a+c)

합의된 결정의 약점:
- 차트에 891·711·822 3개 수치 병기 시 시각적 혼란 가능
- "낮게 잡은 이유"를 굳이 시각화하면 컨설팅이 자신감 없어 보일 수도

**Q2-반박**: 갭을 명시적으로 드러내는 것이 오히려 클라이언트의 의구심을 키울 가능성은 없는가? 갭을 묻어두는 안(예: 권장 711을 base로 차트화하고 891은 텍스트 1줄 언급)이 더 나을 수도 있는가?

## R8 합의 3. 액션 카드 하단 토글로 TIER1/4 소재명 (Q3=c)

합의된 결정의 약점:
- 토글이 인쇄·PDF 변환 시 깨짐
- 토글 안에 묻힌 정보는 발견율이 낮음 — 운영팀이 토글 안 열고 작업할 가능성
- 클라이언트가 토글 안의 소재명에 대해 추가 질문(왜 이 소재가 TIER4? 등) 시 답변 데이터가 카드 내에 없음

**Q3-반박**: 토글 vs inline vs 별도 부록 표 3안 중 인쇄·발견율·데이터 깊이 종합 시 어느 안이 최적인가? 그 근거는?

## R8 합의 4. 부산 1.65M 재계산 (Q4=b)

합의된 결정의 약점:
- 부산은 5월 15일치 데이터만 있음 — 30일 환산이 통계적으로 위험 (분산 매우 클 것)
- 1.65M으로 올렸다가 6월 중순까지 성과 안 나오면 정지 결정 어려움 (sunk cost)
- 다른 신규 지점 추가 시 같은 산식 일반화 불가

**Q4-반박**: 부산 같은 신규 학습 지점에 "일관된 산식"을 강요하는 것이 오히려 위험한가? 옵션 (a) 보수 유지 + 6월 중순 재평가가 더 적절한 시나리오는?

## R8 합의 5. 6월 운영 캘린더 표 1개 (Q5=a)

합의된 결정의 약점:
- 표 1개로 9개 지점·3개 그룹 전체 액션을 W1~W4로 압축하면 지점별 디테일 소실
- W1=OFF, W2=측정 같은 일률적 일정은 지점별 실제 운영 사이클과 안 맞음 (대전 같은 노출 단가 이슈는 측정 주기 다름)
- 클라이언트가 캘린더 보고 "이 일정 누가 책임?" 질문 시 답 없음

**Q5-반박**: 단일 캘린더 표 vs 그룹별 캘린더(A·B·C 3개) vs 캘린더 생략 + 액션 카드 메타로 흩뿌리기 중 어느 안이 실제 실행 가능성을 높이는가?

## R8 합의 6. 별도 6. Next Steps 섹션 신설 (Q6=b)

합의된 결정의 약점:
- 별도 섹션은 의사결정자가 안 읽고 넘길 위험 (긴 제안서일수록 후반 섹션 도달율 낮음)
- 의사결정 요청은 1.1 Executive Summary에 inline되어야 발견율 높음
- 6번 섹션 = "결재해야 할 게 6개나 되나"라는 부담 시그널

**Q6-반박**: 별도 섹션 vs Executive Summary inline vs 1.4 하단 박스 중 클라이언트 의사결정 행동을 가장 빠르게 유도하는 안은? 별도 섹션의 도달율 저하 리스크는 어떻게 완화?
